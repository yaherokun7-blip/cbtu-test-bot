## 🛡️ ระบบยืนยันตัวตน 3 ชั้น (3-Layer Security Verification System)

ระบบนี้ออกแบบมาเพื่อควบคุมไม่ให้บุคคลภายนอกที่ไม่เกี่ยวข้องเข้าถึงห้องเรียนหรือข้อมูลใน Discord Server:

1. **ชั้นที่ 1 (การเข้าถึง):** ลิงก์เชิญส่งเฉพาะในกลุ่ม LINE ของผู้มีสิทธิ์เท่านั้น
2. **ชั้นที่ 2 (การยืนยันตัวตน):** 
   - เมื่อเข้าเซิร์ฟเวอร์ สมาชิกใหม่จะเห็นเฉพาะช่อง `#ยืนยันตัวตน`
   - เมื่อกดปุ่ม **"✅ ยืนยันตัวตน"** จะมีหน้าต่างป๊อปอัปส่วนตัว (Modal Form) ขึ้นมาให้กรอก:
     - **ชื่อ - นามสกุลจริง**
     - **รหัสยืนยันจากกลุ่ม LINE**
   - **เงื่อนไข:** ตรวจสอบเฉพาะความถูกต้องของ **รหัสยืนยันและโควต้า** (ไม่ได้ล็อกตรวจสอบชื่อจริงว่าตรงกับรายชื่อล่วงหน้าหรือไม่)
   - **การจัดการ:** บอทจะบันทึกชื่อ-นามสกุลจริงลงฐานข้อมูลและส่งเข้าห้อง Log เพื่อตรวจสอบย้อนหลัง **โดยไม่มีการเปลี่ยนชื่อเล่น (Nickname) ใน Discord ของผู้ใช้** และมอบยศสมาชิกให้ทันที
3. **ชั้นที่ 3 (การควบคุมและตรวจสอบ):**
   - ทุกครั้งที่มียืนยันตัวตนสำเร็จ บอทจะส่งบันทึก (Audit Log) เข้าห้อง `#bot-log` / `#staff-chat` ทันที สามารถตรวจสอบย้อนหลังได้ตลอดเวลา

## 💬 ตัวอย่างการสั่งงานในช่องแชท (Natural Chat Examples)

ผู้ใช้ที่ได้รับสิทธิ์ต้องขึ้นต้นข้อความด้วย `!admin ` หรือแท็กบอท `@Manager` ก่อนข้อความตัวอย่างด้านล่าง เช่น `!admin สร้างห้องชื่อ ข่าวสาร` ข้อความทั่วไปจะไม่ถูกนำไปสั่งงาน:

### 1. 🔑 จัดการระบบยืนยันตัวตน & รหัสลับ
- `"สร้างระบบ verify"` หรือ `"ทำระบบยืนยันตัวตน"` : ติดตั้งช่อง `#ยืนยันตัวตน` พร้อมปุ่มกด
- `"สร้างรหัส DWMA-2026 30 คน"` : สร้างรหัสใหม่กำหนดโควต้า 30 คน
- `"ดูรหัส"` หรือ `"เช็ครหัส"` : ตรวจสอบรายการรหัสและจำนวนคนที่ใช้ไปแล้ว

### 2. 🧹 ลบข้อความในแชท (Purge / Clear Messages)
- `"ลบ 10 ข้อความให้หน่อย"`
- `"เคลียร์แชท 20 ข้อความ"`
- `"ลบแชท 5"`

### 3. 📁 จัดการช่องแชทและหมวดหมู่ (Channel Management)
- `"สร้างห้องชื่อ ข่าวสาร"`
- `"สร้างช่องเสียงชื่อ ห้องคุยเล่น"`
- `"ลบห้องนี้ที"`
- `"ล็อกห้องนี้"` / `"ปลดล็อกห้องนี้"`
- `"ล้างห้องนี้"` หรือ `"nuke ห้องนี้"` *(ล้างข้อความทั้งหมดและโคลนช่องใหม่)*

### 4. 🛡️ จัดการสมาชิก (Member Moderation)
- `"เตะ @Member ออกจากเซิร์ฟเวอร์ที"`
- `"เตะ @Member เหตุผล กวนเมือง"`
- `"แบน @Member"`
- `"มิวท์ @Member 10 นาที"` / `"ตั้งไทม์เอาท์ @Member 15 นาที"`
- `"ปลดมิวท์ @Member"`

### 5. 🏷️ จัดการยศ (Role Management)
- `"สร้างยศ VIP"`

### 6. 📊 ข้อมูลเซิร์ฟเวอร์และการพูดคุย (General Chat & Info)
- `"สวัสดีครับบอท"` -> บอทตอบกลับทักทายอย่างเป็นกันเอง
- `"ขอข้อมูลเซิร์ฟเวอร์หน่อย"` หรือ `"serverinfo"`
- `"เช็คปิงหน่อย"` หรือ `"ping"`
- `"ทำอะไรได้บ้าง"` -> บอทสรุปเมนูการใช้งานให้ทันที

## ⚡ คำสั่ง Slash Commands (`/`) สำหรับแอดมิน

- `/create_code <code> <max_uses> [role_name]` : สร้างรหัสยืนยันตัวตนพร้อมโควต้า
- `/list_codes` : ดูรายการรหัสทั้งหมดและโควต้าที่ใช้ไป
- `/delete_code <code>` : ลบรหัสที่ไม่ต้องการ
- `/setup_verify` : ส่งปุ่มยืนยันตัวตนลงในช่องปัจจุบัน
- `/kick`, `/ban`, `/unban`, `/timeout`, `/untimeout`, `/purge`
- `/create_channel`, `/delete_channel`, `/create_category`, `/slowmode`, `/lockdown`, `/unlock`, `/nuke`
- `/create_role`, `/delete_role`, `/add_role`, `/remove_role`
- `/serverinfo`, `/userinfo`, `/ping`

## การป้องกันคำสั่งผิดและข้อมูลยืนยันตัวตน

- คำสั่ง `ลบห้องนี้`, `ล้างห้องนี้`, `/delete_channel` และ `/nuke` แสดงปุ่มยืนยันก่อนทำงาน ผู้สั่งเดิมที่ยังมีสิทธิ์ต้องกดภายใน 60 วินาที ยกเลิก/หมดอายุ/กดซ้ำจะไม่ทำงาน
- `!admin จัดโครงสร้าง` ตามด้วยรายการหมวดหมู่และห้อง เป็นการเพิ่มโครงสร้าง คำว่า `template` หรือรายการตัวเลขอย่างเดียวไม่ทำให้ลบห้อง
- หากต้องการล้างโครงสร้าง ใช้ `!admin ล้างเซิร์ฟเวอร์` หรือ `!admin เคลียร์ดิสคอร์ด` ตามด้วยโครงสร้างใหม่ บอตแนบรายการห้องเดิมและโครงสร้างใหม่ให้ตรวจสอบก่อนกดยืนยัน ลบเฉพาะห้องเดิมในรายการที่ยืนยัน และจะไม่เริ่มลบถ้าสร้างโครงสร้างใหม่ไม่ครบ
- Gemini ใช้ตอบคำถามเท่านั้น ผลลัพธ์จาก AI ไม่สามารถสั่งลบหรือแก้เซิร์ฟเวอร์โดยตรง
- แจกยศล้มเหลวจะไม่ใช้โควต้าและไม่บันทึกว่าผ่าน สามารถลองใหม่ได้ หากบันทึกไฟล์ล้มเหลวหลังแจกยศ จะพยายามถอดยศคืนและแจ้งข้อผิดพลาด
- ทุกเส้นทางแก้ข้อมูลยืนยันตัวตนใช้ lock ร่วมกัน ไฟล์ถูกเขียนผ่านไฟล์ชั่วคราวแล้วแทนที่แบบ atomic หากไฟล์เสียจะหยุดและแจ้งข้อผิดพลาด ไม่เริ่มฐานข้อมูลว่างทับของเดิม
- ระบบ JSON นี้ใช้กับ **บอตหนึ่งโปรเซสและหนึ่งเซิร์ฟเวอร์** อย่ารันหลายโปรเซสร่วมไฟล์เดียวกัน การแก้นี้ยังไม่ได้เปลี่ยนเป็นฐานข้อมูลที่รองรับหลายโปรเซสหรือแยกข้อมูลหลายเซิร์ฟเวอร์

หลังเปลี่ยนไฟล์ ให้เริ่มบอตใหม่เพื่อโหลดโค้ดและ `.env` ใหม่:

```powershell
python main.py
```

รันทดสอบอัตโนมัติจากโฟลเดอร์ `discord-admin-bot` (ใช้ข้อมูลจำลอง ไม่เชื่อมต่อ Discord):

```powershell
python -m unittest discover -s tests -v
```
